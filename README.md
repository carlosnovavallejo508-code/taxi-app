# 🚕 Taxi App

Aplicación de taxi completa con 4 aplicaciones:
- **Passenger App** (Pasajero)
- **Driver App** (Conductor)
- **Admin Dashboard** (Administrador)
- **Business Portal** (Negocios)

## Stack Tecnológico
- Backend: Go
- Frontend: React + TypeScript
- Base de datos: PostgreSQL
- Cache: Redis
- Contenedores: Docker
